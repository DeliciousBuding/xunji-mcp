# v0.3.0

[English](#english) | [简体中文](#简体中文)

## English

An optional MCP Apps view presents the training overview while retaining the
existing text result.

### Changes

- `ui://xunji/overview`, served as `text/html;profile=mcp-app`, with KPI tiles,
  a monthly volume chart, a coverage badge and host-theme support.
- Overview tool metadata includes `_meta.ui.resourceUri` and the ChatGPT Apps
  SDK `openai/outputTemplate` when `MCP_UI_ENABLED=true`.
- A self-contained HTML resource with no external requests and no additional
  data access. Text remains the fallback.

### Upgrade and configuration

From v0.2.1, retain the existing OAuth, D1, scanner and cron configuration.
No new schema migration is introduced. `MCP_UI_ENABLED` defaults to `false`;
enable it only when the target client supports MCP Apps and verify rendering
in that client.

The UI does not change write authorization. Training writes remain real
opt-in operations requiring `WRITE_TOOLS_ENABLED=true`, `xunji:write` and
`confirmed: true`, with no `dry_run` or delete tool.

### Validation scope and known limits

The tagged acceptance record reports earlier disabled/enabled resource,
MIME/metadata tests and an operator tool/resource-list check. This release body
reconstructs that record; it does not rerun tests or verify visual rendering.

Real ChatGPT MCP Apps rendering remains client pending. Registration and
`openai/outputTemplate` metadata do not establish client compatibility.
Operator key rotation and live body/nutrition verification remain pending.
The view shows existing indexed results, whose coverage and freshness still
need to be checked.

## 简体中文

新增可选 MCP Apps 视图展示训练概览，并保留已有文本结果。

### 变化

- 提供 `ui://xunji/overview`，MIME 类型为 `text/html;profile=mcp-app`，
  包含 KPI 卡片、月训练量图、覆盖标记和宿主主题支持。
- `MCP_UI_ENABLED=true` 时，概览工具 metadata 包含 `_meta.ui.resourceUri`
  和 ChatGPT Apps SDK 的 `openai/outputTemplate`。
- HTML 资源自包含，不发起外部请求，也不增加数据访问；文本保留为回退输出。

### 升级和配置

从 v0.2.1 升级时，保留已有 OAuth、D1、扫描器和 cron 配置。
本版本没有新增 schema migration。`MCP_UI_ENABLED` 默认为 `false`；
目标客户端支持 MCP Apps 时再启用，并在该客户端验证渲染。

UI 不改变写入授权。训练写入仍是真实操作，
需要 `WRITE_TOOLS_ENABLED=true`、`xunji:write` 和 `confirmed: true`，
没有 `dry_run` 或删除工具。

### 核验范围与已知限制

Tag 中的验收记录记载了既有关闭及启用资源、MIME 和 metadata 测试，
以及操作者工具和资源列表检查。
本 Release 文案据此整理，没有重新运行测试或验证视觉渲染。

真实 ChatGPT MCP Apps 渲染仍待客户端确认。
资源注册和 `openai/outputTemplate` metadata 不能证明客户端兼容。
操作者 Key 轮换及身体、饮食数据真实核验仍待完成。
视图显示已有索引结果，其覆盖范围和新鲜度仍须检查。
